# Bossku Finance OS Design System

This app uses a Binance-inspired dark financial dashboard system.

## Tokens

- `canvas-dark`: `#0b0e11`
- `surface-card-dark`: `#1e2329`
- `surface-elevated-dark`: `#2b3139`
- `primary`: `#fcd535`
- `primary-active`: `#f0b90b`
- `on-primary`: `#181a20`
- `on-dark`: `#ffffff`
- `body`: `#eaecef`
- `muted`: `#707a8a`
- `hairline-on-dark`: `#2b3139`
- `trading-up`: `#0ecb81`
- `trading-down`: `#f6465d`
- `canvas-light`: `#ffffff`
- `ink`: `#181a20`

## Semantics

- Income and money in use `trading-up`.
- Expenses and money out use `trading-down`.
- Debt totals, primary CTAs, progress fills, and current selections use `primary`.
- Money values use IBM Plex Mono with tabular numerals.
- Depth comes from surface contrast and borders, not shadows or gradients.
